# Sky Emotions FR

Site Next.js français (copie indépendante de SkyemotionsES).

## Démarrage

```bash
cd SkyemotionsFR
npm install
npm run dev
```

## Variables d’environnement

Voir `.env.example` :

- `NEXT_PUBLIC_SITE_URL`
- `STRIPE_SECRET_KEY`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- (optionnel) Resend pour recevoir le formulaire post-paiement

## Routes

- `/` Accueil
- `/reservation`
- `/bons-cadeaux`
- `/tarifs`
- `/le-centre`
- `/contact`
- `/info`, `/info/conditions`, `/info/le-saut`, `/info/faq`
- `/checkout`, `/checkout/success`

Non lié au site espagnol.
